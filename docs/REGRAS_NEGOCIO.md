# Regras de Negócio do GCF

## Propósito
O sistema deve apoiar a rotina de um consultor financeiro e especialista em BPO Financeiro com foco em organização, controle e acompanhamento profissional.

## Regras Gerais
- Cada cliente deve ter um registro claro e organizado
- As atividades devem poder ser acompanhadas por data e status
- Pendências devem ser visualizadas com prioridade
- Documentos devem ser armazenados de forma estruturada
- Indicadores devem refletir a operação de forma objetiva

## Regras de Uso
- As informações devem ser apresentadas de forma clara e objetiva
- O sistema deve favorecer a produtividade do usuário
- A navegação deve ser simples e profissional
- O ambiente deve manter consistência visual e funcional

## Critérios de Qualidade
- Informações essenciais devem estar acessíveis rapidamente
- A experiência deve ser confiável para uso diário
- O sistema deve apoiar decisões operacionais e estratégicas
