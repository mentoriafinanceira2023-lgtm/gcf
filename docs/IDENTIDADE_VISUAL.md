# Identidade Visual do GCF

## Diretrizes de Apresentação
A interface do sistema deve transmitir profissionalismo, confiança e modernidade.

## Paleta
- Azul-marinho: cor principal, associada à seriedade e à estrutura corporativa
- Amarelo: cor de destaque, utilizada para chamar atenção para elementos importantes
- Cinza muito claro: fundo base, promovendo leitura confortável e visual limpo

## Estilo Geral
- Layout organizado e moderno
- Visual corporativo
- Elementos limpos, com boa hierarquia
- Design responsivo e consistente

## Aplicação Esperada
- Navegação lateral clara
- Cabeçalho objetivo e funcional
- Cards e blocos com aparência profissional
- Ênfase visual em dados e ações prioritárias
